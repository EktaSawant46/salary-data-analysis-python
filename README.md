# Salary Dataset Analysis using Python (Beginner Level)

# Project Overview
This beginner-level project focuses on loading, inspecting, and understanding a dataset using Python and Pandas.  
The aim is to learn how data analysts explore a dataset before performing data cleaning or visualization.

# Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

# Dataset
- File: Salaries.csv
- Contains salary-related information of employees
- Dataset includes missing values

# Tasks Performed
- Imported required Python libraries
- Loaded CSV data into a Pandas DataFrame
- Displayed top and bottom rows of the dataset
- Checked number of rows and columns
- Analyzed column names and data types
- Identified missing values in each column

# What I Learned
- How to load real-world data using Pandas
- How to explore dataset structure
- How to identify missing values
- Importance of data understanding before analysis
